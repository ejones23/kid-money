# Kid Money support

Kid Money is under active development. For help, bug reports, or feature requests, [open an issue in the public Kid Money repository](https://github.com/ejones23/kid-money/issues).

Please do not include children's names, balances, transaction history, device logs containing personal information, or other private information in a public issue. Describe the behavior using fictional names and amounts instead.

The project source and current development status are available in the [Kid Money repository](https://github.com/ejones23/kid-money).
