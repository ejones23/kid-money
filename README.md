# Kid Money

A small, local-first iPhone ledger for tracking money owed to children. The first milestone is a reliable Siri interaction; the app itself provides a minimal manual fallback and history view.

## Status

Phase 1 is in progress: SwiftUI + SwiftData ledger persistence, child creation, derived balances, and a manual +$0.10 action.

## Open in Xcode

Open `KidMoney.xcodeproj`, choose an iPhone simulator or your signed physical iPhone, then Run. The project's deployment target is iOS 26.0.

## Product naming

The app display name is **Kid Money**. For a remote repository, `kid-money` is concise and descriptive; `kid-money-ledger` is a good alternative if you want the ledger emphasis. `kid_money_ledger_app` is more verbose than needed.
